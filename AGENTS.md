## Principles

- Challenge readme files do not provide information that should be in the rama skill
- A challenge readme, and the test-support namespace should be minimally
  sufficient to allow the challenge to pass when the rama skills are
  use/

- Challenge reference solutions and private tests under the runner's protected
  paths are encrypted during solver runs and decrypted afterward. Do not assume
  other files (for example, docs or atlases) are protected by that mechanism.

Claude Code imports this file from the root `CLAUDE.md`, which also contains
Claude-specific commands and conventions. Project skills live in
`.agents/skills/`; the publishable Rama skill remains in
`plugins/rama-skill/skills/rama/`.
