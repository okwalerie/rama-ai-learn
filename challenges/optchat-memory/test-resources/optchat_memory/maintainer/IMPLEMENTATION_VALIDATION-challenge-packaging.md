## Contract, bound and fault traces

Append (289–292, 215–234): validate Unicode/types/exact fields before ingress; normalize timestamp to Long. A new key writes original, ready leaf and final part, updates totals/pending/watermark and records index atomically. Existing key compares all payload fields before capacity. Final allocatable index is MAX-1. The maintainer-only boundary fixture seeded that watermark and 2^80 metadata, accepted the last message, then verified capacity refusal, identical retry and conflict in actual two-worker IPC.

Extraction (37–58): bounded original <=65,536 bytes; leaf units retain LF/CRLF; parent has exactly two immutable texts <=512 each. Accumulate only leading whole units while suffix fits; oversize first unit produces a descriptor with no leading LF. Omission ancestry survives free concatenation. Stored representation bytes are Long, while aggregate deltas and revisions are explicitly normalized to BigInteger (63–73, 200–206). A real PState plus query/update roundtrip verified 2^80 values and class, not just serializer source inspection.

Eligibility (112–120,151–160): every new immutable node probes its one sibling; both-ready means insert only its absent immediate parent. Building removes its own work index, may enqueue its parent, decrements pending once, and checks current child parts for usefulness. A complete parent cannot preexist its newly created child. Counter oracle enumerates every complete binary address independently.

Merge candidates (122–175): aligned siblings form a unique pair. Removing a candidate probes one remaining head to clear the bounded level flag. Building a parent inserts only if both children are current parts and bytes strictly decrease. Merging removes only its consumed pair, replaces two parts with parent, and checks its unique aligned higher sibling. Other candidates cannot overlap those consumed aligned same-level parts. At each nonempty level the oldest start maximizes due score; exact cross-products compare <=63 heads. A constructed public trace at T=20 gives candidates 0+4 and 10+2 both score 5/2 and verifies smaller start wins, including concurrent identical compact requests.

Compact (177–206,235–249): <=32 sequential actions, recomputing next decision every step. Over-budget useful merge precedes building; otherwise smallest eligible count/start builds. No-op preserves revision; any positive action count increments once. The first test run exposed an incorrect branch-local revision rebinding; it was fixed by explicitly emitting both updated values, and every original failing assertion remains. Durable receipt stores the final whole result; later appends and module update do not change a retry's old watermark/revision.

Page (250–263): metadata first, then missing→stale→range/boundary precedence. Current terminal cursor returns empty without part I/O. Nonterminal reads <=64 rows with the first start also validating boundary, including a start inside the last merged part. No second node lookup per returned part. Query owns one nonyielding task segment, so its metadata and rows agree. Zoom children (264–275) use overflow-safe endpoint check then two probes; absent nodes become pending. Leaf/date (301–311) are one point read. None of these reads mutate state or initiate work.

Measured timings below are IPC test wall time, not production latency/throughput benchmarks. Fixed nested-index physical seek overhead was not measured; the plan's logical-read cost model remains a model. Full traversal is O(returned parts) across bounded pages; unbounded durable history still grows storage.
