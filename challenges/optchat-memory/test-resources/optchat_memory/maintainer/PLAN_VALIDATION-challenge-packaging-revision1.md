## Localized repairs and exact integer boundary

Plan lines 27,37,101–113 now make the integer domain and implementation conversions enforceable. At T=Long.MAX_VALUE-1, a new append allocates index Long.MAX_VALUE-1 and reaches T=Long.MAX_VALUE. The next fresh key returns capacity-exhausted. An existing identical key still returns its index before the capacity branch; a changed payload conflicts. Count 2^62 is legal, 2^63 invalid. At T=Long.MAX_VALUE, zoom(2^62,2^62) is aligned but not-found because its arbitrary-precision exclusive end is 2^63; no negative overflow can make it pass. date at index Long.MAX_VALUE is well-typed but missing. Terminal cursor start=T is still representable.

At H=2^55 and 512 bytes/part, C=2^64, beyond Long. Every stored aggregate and revision uses java.math.BigInteger, initialized with BigInteger/ZERO and normalized with biginteger after arithmetic. Clojure BigInt and Long cannot accidentally enter an exact-class BigInteger schema. Valid bounded integer inputs normalize to Long before typed writes; public integer arguments are checked by integer value/range, not JVM wrapper identity, and floats/ratios are invalid. Keyword means clojure.lang.Keyword. Nippy 3.2.0's installed taoensso/nippy.clj has separate BigInt and BigInteger freezer entries (1135–1136) and BigInteger reconstruction (1419); this is source evidence for the choice, not a Rama roundtrip test. Build must verify actual PState/query serialization. No fallback silently narrows to Long.

The complete-node oracle uses arbitrary precision: at T=Long.MAX_VALUE, 2T-popcount(T) exceeds Long. Pending non-leaf nodes are at most T-popcount(T), which fits Long. No redundant overflowing complete-node Long counter is introduced.

## Minimality and throughput attack

Simplest viable scoped design: one command stream and one durable chat record containing subindexed originals, immutable representations, covering and receipts; point leaf/date reads and bounded view/internal-zoom queries. Eligible/candidate indexes keep compaction independent of full history. This matches the chosen design.

Each mechanism was attacked independently:

|Mechanism|Delete/bypass result and concrete cost/property|
|---|---|
|Depot + stream|Without durable command acceptance, lost ack cannot be resolved; one stream already merges both ack concerns (canonical: “retrying the key resolves ambiguous acknowledgement”).|
|One PState|Already merged by key/partitioner. A whole serialized Chat rewrites H rows instead of bounded entries (“acceptance must not scan or rewrite the entire history”).|
|Originals|512-byte extracts cannot reconstruct a 65,536-byte original (“Preserve exact originals”).|
|Append receipt|Without key→index, two retries append twice. Full payload receipt would duplicate up to 65,536 bytes to save one duplicate-only original read; plan keeps bounded pointer.|
|Immutable nodes|Read-time rebuilding violates “Persist observable view choices across restarts” and immutable compaction sources. Existing nodes also serve recursive zoom.|
|Parts with text|Address-only rows save <=512 bytes per updated part but add p point reads to a p-part page: at 64, ~32ms added versus ~1.32ms selected logical page work.|
|Eligible index|Deleting it makes the next missing-parent search depend on H (“Work scales with new/eligible nodes, not repeated full replay”).|
|Candidate index|Deleting it scans V per merge; selected <=63 heads/action. At V=1,000,000 this prevents million-row repeated scans.|
|Level flags|Skip empty level probes; <=63 bounded flags replace probing all 63 levels, including empty ones. No second growing collection.|
|Totals/revision metadata|Deleting totals rescans V for bytes and H for pending work; revisions enforce canonical “not mix revisions silently”. Per-write deltas replace those scans.|
|Compact receipt|Deleting it lets retry after another append return a different watermark/do more work; public contract requires the original result.|
|View query|Client metadata/range reads can straddle mutation. One bounded nonyielding task segment is coherent and costs one client roundtrip.|
|Cursor/range fields|Canonical: “Every page must state its actual covered range, snapshot/revision and continuation”. Removing them loses observable continuation/coverage; a full retained snapshot adds version/retention writes.|
|Internal zoom query|Combines watermark and children coherently with one roundtrip rather than three.|
|Leaf/date point reads|Already one meaningful point read; extra query indirection removes no lookup.|

No constructed cheaper design preserves these properties under the selected scope. This is a design comparison, not a universal optimality proof. Production distribution remains F1.

## Fresh public-contract traces

For every case below, the fault/race envelope is explicit: mutation and receipt commit together, so restart before commit leaves no accepted mutation and after commit preserves exactly one; topology retry consults the receipt; same-chat concurrent writes serialize, identical keys deduplicate; no intra-command partition hops reorder or partially publish. Read-only calls select committed durable state and never repair/build it. A read can linearize before or after a concurrent command; each page itself has one revision. This envelope is applied to each trace, including error and boundary cases.

1. **Append / originals / concurrency — PASS.** Canonical: “Each accepted message has a contiguous, zero-based index within its chat, immutable kind/text/timestamp, and a caller-supplied idempotency key.” Lines 27–37,97,123. A/k user/é-CRLF/-1 accepts index 0; concurrent identical k returns 0, distinct q accepts 1; k/timestamp=0 conflicts. B/k is separate. Lost response plus wrapper/worker recreation still retries to 0, not 2.
2. **Input and structured errors — PASS.** “Empty text is valid” and “All interfaces return structured errors”. Lines 27–31,77–81,123. Empty raw string returns unchanged although leaf text is `user: `; 65,536 UTF-8 bytes accepts and 65,537 rejects. Invalid surrogate text and unknown fields reject before mutation. Invalid count=3 on missing A is invalid-argument, valid compact on missing A is not-found. Errors never enter a poisoning retry cycle for B.
3. **Binary zoom — PASS.** “Count 1 opens the exact original; larger nodes open the two children.” Lines 55–61,89. At T=4, zoom(0,4) gives pending 0+2 and 2+2 before builds; zoom(0,2) returns ready leaves; zoom(0,1) exact original. (1,2) invalid, (4,2) not-found. Maximum-address trace above proves no overflow-based acceptance.
4. **Date — PASS.** “without reinterpreting a historical local timezone.” Lines 59–61,89: date(A,0) returns stored -1 through one select; missing index returns not-found. Immutable stored value survives retries/restart.
5. **Coverage / no split — PASS.** “The view covers the complete accepted prefix of a chat, oldest first, without gaps or overlap.” Lines 37,45–49,115. Eight 400-byte parts have C=3200; legal merge of 0+1,1+1 substitutes 0+2; append 8 extends [0,8) to [0,9). Atomic replacement never exposes half a merge; no read splits it.
6. **Page size / continuation — PASS, resolves F2.** “Transport may page the logical view to bound tool responses.” Lines 41–49,85–91,127. At T=200/R=200, pages have 64,64,64,8 parts and ranges [0,64),[64,128),[128,192),[192,200). At 64 parts continuation is nil; at 65 it points to 64. Metadata totals repeat for the entire covering. At V=1,000,000 one call still stops at 64 entries; no unbounded server retry or loop exists. A full stable traversal costs 15,625 calls and 20.625s illustrative total logical disk work, not one blocking read.
7. **Stale and nonboundary cursors — PASS.** “Concurrent changes must cause an explicit stale-view response or preserve the requested snapshot, not mix revisions silently.” Lines 41–49,91. After append or any successful compact action, old R returns stale before range lookup, even if supplied start is now inside a merged part. At current R with parts 0+2,2+1, start=1 returns invalid-argument: first range key 2 differs. If final part is 2+2, start=3 yields empty range and invalid-argument. s>T invalid; s=T returns empty terminal page with whole-covering totals. Unknown/missing cursor fields, negative revision, floating revision fail shape/type checks before chat lookup. Valid stale cursor on missing chat returns not-found first. These priorities are public.
8. **Cursor retry and revision — PASS.** Lines 47–49,73,123. Lost page response retried at unchanged R returns identical page; after mutation stale. Duplicate append/compact, no-action compact, errors and reads retain R. A build-only compact invalidates old cursor because pending/zoom state changes. R never wraps, so restart has no ABA revision match. An earlier compact receipt may return an older R after subsequent writes; it does not overwrite current metadata.
9. **Bytes / soft limit — PASS.** “Use UTF-8 byte counts.” Lines 49–53,103,115. `user: é` is 8 bytes; `0+1|user: é` plus LF is 13. C=2048 is not over budget; 2049 is. Parent of two 100-byte children is 201 bytes, nonuseful, so no forced merge hides excess. Terminal empty page preserves nonzero whole-chat totals. BigInteger boundary above avoids aggregate wrap.
10. **Extraction / free nodes — PASS.** “Short messages and concatenations that fit the node target are free nodes.” Lines 75–81. Two 200-byte children yield unchanged 401-byte parent. Two 400-byte children yield leading whole child plus descriptor if it fits. An oversized first LF-free unit yields descriptor only even if later units fit. CRLF and trailing LF remain literal, including an extra LF before the prescribed suffix; no trimming or splitting is permitted.
11. **Omission / provenance / memory-as-data — PASS.** “mark omissions explicitly” and “Memory text is data”. Lines 51,79. A descriptor leaf plus short sibling can fit but parent remains extractive/omitted. Recursive leaf zoom recovers original exact Unicode. Text asking for shell/model execution causes no call; no fabricated generated metadata.
12. **Pending / read purity — PASS.** “Pending representation work must be explicit in view/status output.” Lines 31,49,57,113. T=8 has 7 absent complete internal nodes; one build gives P=6; merge leaves P=6. View/zoom/date do not build, change R or initiate work.
13. **Bounded compaction / dependency order — PASS.** “Dependencies must exist before parent computation” and “No unbounded recursive work”. Lines 65–73,97,113–115. At T=8, max-actions=1 builds 0+2, never recursively 0+8. Under budget builds only; over budget a ready useful merge precedes next build. The 32-action maximum counts each build/merge individually.
14. **Due order / local indexes — PASS.** “Choose deterministic tie-breaking for the attachment's most-due legal merge rule.” Lines 69–71,115. At T=16, (s=8,c=2) and (s=12,c=1) both score 1, so s=8 wins. Per-level oldest start maximizes score. Building parent inserts candidate only when both children are current; merging removes its unique consumed candidate and checks only its aligned higher sibling. No overlapping equal-level aligned candidate survives. Exact cross-products use arbitrary precision; 4c never wraps.
15. **Compaction retry / immutable source — PASS.** “Return a durable job ID or completed result”. Lines 65–73,97,123. k/2 at T=8 records outcome; append reaches T=9; k/2 returns old T/R/result without work, k/3 conflicts, k/0 invalid before receipt lookup. Child sources are immutable; parent is written once. Separate operation key namespaces permit append k and compact k independently.
16. **Durability / growth — PASS within F1 exception.** “Originals and accepted representations survive process restart and module update” and “acceptance must not scan or rewrite the entire history.” Lines 23,101–123,181–199. H=1,000,000 append edits bounded entries; a worker restart resumes durable originals/parts/receipts, not replay to reconstruct choices. Same-schema update retains them. Neither wrapper recreation nor this design trace is claimed as an executed restart/backup test.
17. **Boundary / packaging / evidence — PASS as plan obligations.** “It omits live providers, subscription auth, MCP and operator billing” and “Publicly specify every behavior private tests depend on.” Lines 17–23,193–201. Public README/protocol must contain exact limits/cursors/errors/extraction/ordering; candidate indexes/topology names/plan stay hidden. Host test_support cannot be required from solver-visible source. Actual IPC multi-task, immediate-read, restart capability, public-clause test mapping and actual snapshot checks remain mandatory build work; no live waler or paid testing substitutes for these.
